## Commands

- Use npm; `package-lock.json` is the only lockfile. Next.js requires Node.js 20.9 or newer.
- Install with `npm ci`; run the app with `npm run dev`; verify production with `npm run build`. `npm run start` requires a completed build.
- There are no test, formatter, or standalone typecheck scripts. For a standalone type check, run `npx next typegen && npx tsc --noEmit` in that order; `LayoutProps` in `app/layout.tsx` is generated by Next.js.
- `npm run lint` includes `references/pantallas/support.js` and currently fails there. Use `npm run lint -- app` for focused app linting; do not fix the repository-wide baseline by editing that generated file.

## Project Boundaries

- `app/` is the only runtime source tree and uses the App Router. The `@/*` alias resolves from the repository root, not from `src/`.
- `references/pantallas/` and `references/screenshots/` are design inputs, not implemented routes, authentication, or data flow.
- `references/pantallas/support.js` is generated from an absent `dc-runtime` project. Do not edit it; its stated rebuild command cannot run in this repository.
- Tailwind CSS 4 is configured through `postcss.config.mjs` and `@import "tailwindcss"`; there is intentionally no `tailwind.config.*`.
